# Shellfox 0.6.0

## Terminal commands

- Added session listing, confirmed deletion, session status controls, current-tab controls, keep-alive toggling, and version output.
- Added session/tab memory and duration statistics, plus process trees with PIDs.
- Added command aliases and filters, including `--current`. See [CLI reference](../cli.md) or `shellfox help`.
- Windows, WSL, Linux and macOS launchers route controls to the running manager through an authenticated local endpoint.
- CLI keep-alive changes update the app's eye button immediately.

## Validation

Local validation on Windows x64:

- Typecheck passed.
- Unit suite: 1,947 passed, 46 platform-specific or opt-in tests skipped.
- Packaging configuration: 12 passed, including execution of the shipped Debian launcher.
- Production build passed; built CLI version and command help verified.
- Real Electron SQLite and PTY smoke tests passed.
- Isolated Windows/WSL launcher routing passed.
- Real Electron CLI end-to-end tests passed, including confirmation/cancellation, current-tab identity, real PID/RSS measurements, and destructive session controls completing after closure of the invoking terminal.
- Full GUI rerun: 30 passed, 3 skipped, 2 failed. The failures were the existing Pi busy/idle activity assertion and WSL clipboard startup input contamination. The clipboard test passed in one isolated repeat and failed in another. These failures remain unresolved; the full GUI suite is not green.

Cross-platform installer builds and packaged smoke tests run in the release workflow. Local validation does not certify Linux or macOS installers.
