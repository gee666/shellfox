# Shellfox 0.9.14

- Terminal links to folders now open in the folder browser. Relative links resolve from the terminal's current directory. If a link can't be opened, the error appears in the middle of the file area with the full path that was searched and a copy button. Desktop and mobile behave the same way.
- New empty text files, with any extension, can be created from the file browser (the + button on desktop, "New file" in the folder menu on mobile). Existing files are never overwritten.
- Pinned sessions are never settled or deleted automatically.
- Session order is now stable: pinned sessions first, then status, then newest created, then name. Activity timestamps no longer move rows. The same order applies on desktop, mobile and in the CLI.
- Test fixes: the SSH end-to-end fixture ignores keys from a developer's SSH agent, the CLI binding test creates private data folders on any umask, and the remote file transfer test gets enough time for approval.

Linux validation before release: desktop/mobile typechecks passed, and 4,048 unit tests passed with 57 skipped. New Electron end-to-end tests for folder links, missing-link errors and file creation passed. Release CI builds and checks desktop, headless and Android packages.
