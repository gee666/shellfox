# Shellfox 0.9.13

- Added system file-manager buttons for local files and folders, a collapsible sessions sidebar, and shortcuts for the sessions, files, and folders panes. File controls now share one compact row, and upload/download controls appear only for remote filesystems.
- The explorer path field opens folders or a file's parent folder and preview. Missing folders require confirmation before creation. Terminal file and folder links now handle wrapped paths using the same row-mapping helper as web links.
- Fixed mobile terminal cursor-position edits, selected-text replacement, and deletion with native keyboards and IMEs.
- Fixed settled sessions resuming from terminal mouse hover. Desktop, mobile, and headless clients now distinguish terminal input from mouse reporting.

Windows validation before release: desktop/mobile typechecks passed; 4,032 unit tests passed with 59 platform-dependent tests skipped; browser tests, the test build, and both Electron layout tests passed. Mobile terminal browser tests and headless contract tests also passed. Release CI builds and checks desktop, headless, and Android packages. iOS metadata is updated to 0.9.13, build 9013; iOS distribution is not part of this workflow.
