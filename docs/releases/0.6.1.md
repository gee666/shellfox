# Shellfox 0.6.1

Includes the CLI commands documented in [0.6.0](0.6.0.md), which did not publish because its Windows packaging test failed.

The Debian launcher test now obtains its expected physical directory from the shell. Git Bash on the Windows CI runner maps the workspace scratch directory to `/tmp`; converting the drive letter alone produced a different spelling of the same directory. Launcher behavior is unchanged, and the test still checks exact arguments, directory selection, aliases and exit codes.

Local validation: packaging tests passed, 12 of 12; typecheck passed. The four Linux/macOS packaging jobs had already passed for 0.6.0. The new tag reruns the full release matrix. The GUI test limitations recorded for 0.6.0 remain unchanged.
