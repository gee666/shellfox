# Shellfox 0.9.7

- Mobile Paste opens with clipboard text already filled in. Text remains editable and is sent only after tapping Send.
- Mobile startup shows a loader while saved connections and sessions load instead of briefly offering Settings.
- New desktop terminals focus the typing area automatically, including delayed startup and replay.
- Typing in a settled terminal automatically resumes the session. Passive output and terminal protocol replies do not unsettle it.
- Mobile terminals support file attachments and avoid duplicate IME input.
- Closed terminal cleanup and process tracking are more reliable.
- Linux terminal processes are isolated from OOM kills where supported. Desktop shutdown handles OS termination without leaving owned shells behind.

Upgrade hosts and clients together for input provenance support. Restarting an owning host ends its app-owned shells. Publication does not restart existing installations.

Local Windows validation: desktop/mobile typechecks passed, 3,333 unit tests passed with the unrelated Linux scope test excluded, and 37 mobile terminal Chromium tests passed. The Linux scope test fails on this Windows machine. Local desktop end-to-end testing was blocked by missing Go. Release CI builds and checks desktop, headless and Android deliverables. iOS metadata is updated to 0.9.7, build 9007; iOS builds and device acceptance are not part of the release workflow.
