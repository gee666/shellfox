# Shellfox 0.9.6

- Fixed mobile terminal input, special keys and terminal ownership handling.
- Fixed remote activity recovery and terminal creation controls.
- Added verified headless CLI updates for Windows, macOS and Linux, with a stable launcher path after upgrades.
- Removed the desktop terminal ownership notification toast.

Upgrade hosts and clients together for the terminal control fixes. Restarting an owning host ends its current app-owned shells. Publishing this release does not update or restart existing installations.

Local checks on Windows with Node 24.22.1: desktop/mobile typecheck passed, 3,178 unit tests passed with 56 platform-dependent tests skipped, and all 49 packaging tests passed. The release workflow runs native packaging and smoke tests for the supported desktop/headless targets and Android emulator checks. iOS metadata is updated to 0.9.6, build 9006; iOS compilation and distribution are not part of this release workflow.
