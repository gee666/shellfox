# Shellfox 0.9.15

- Windows desktop and headless hosts use a fixed, private path for the embedded Tailscale helper, so Windows Firewall can reuse approval across updates. Development and test builds have a separate fixed path. Windows may ask once for each new path.
- Windows native Go tests, including `nethealth`, run from fixed executable paths rather than random Go build folders. Use `pnpm test:tailscale` or `pnpm test:mobile:native` to retain approval between runs.
- On mobile, swipe right from a terminal, host header or session row to open Files. Swipe left in Files to return. Swiping preserves the folder, scroll position, open file and text draft. Image-editing gestures remain available; use Hide files to return while editing an image.
- Tapping the mobile folder button starts a fresh browser at the host's home folder or the terminal's current folder, with a discard prompt for unsaved edits.
- Mobile sticky modifiers release 430 ms after the last input. The adjustable release-delay setting has been removed without resetting other preferences.

Windows validation before release: desktop/mobile typechecks, 4,038 unit tests, native Windows and mobile Go suites, launcher process-lifetime checks, and packaging contracts passed. Release CI checks the packaged desktop, headless and Android products. Firewall prompt acceptance still depends on Windows network profiles and administrator policy.
